# Repository instructions

## Purpose
This repository contains the Sign In With Solana specification and a reference dapp implementation.

## Layout
- `README.md` is the SIWS specification and integration guide.
- `example-dapp/` contains the React reference implementation.
- `assets/` contains documentation assets.

## Commands
Run application commands from `example-dapp/`:

- `npm install` installs dependencies.
- `npm start` starts the development server.
- `npm run build` creates a production build.
- `npm test` runs the React Scripts test suite.
- `npm run tsc` runs TypeScript type checking.

## Working in this repository
Keep the specification, message examples, and reference implementation aligned. Preserve the ABNF message format and documented verification constraints when changing SIWS behavior.
